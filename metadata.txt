about=SSO edition of GeoServer Publisher; installs side by side with it. Publishes vector layers to GeoServer using plain HTTP requests to workspace-scoped endpoints only, so a workspace-level user works. "Sign in with Microsoft" opens Microsoft Edge (or Chrome) at your GeoServer, you sign in as usual, and the plugin reuses that session's cookies (kept in memory only). A redirect to a sign-in page is reported as a failure, never as success, and every REST publish is verified on the server. Includes a WFS-T append mode that needs no REST access. Every request/response is logged in detail with secrets redacted.
